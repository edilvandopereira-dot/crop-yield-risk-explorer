Compare shortfall counts using the preceding three-year or five-year arithmetic mean. The evaluation window stays fixed at 2016–2025. Each state uses only years with a valid current yield and both references.

At a 10% threshold, Rio Grande do Sul changes from 3/10 to 4/10 years; Paraná changes from 2/10 to 1/10. Mato Grosso remains 1/10. Reference choice changes the description, even with the same observations.

What changes and what stays fixed

The reference length and shortfall threshold are separate assumptions. Change one at a time. An event is an annual reported yield strictly below (1 − threshold / 100) × its trailing mean. The reference excludes the current and future years. Missing historical years invalidate that reference. Counts are paired on the intersection of valid years, so the denominator cannot change between the two columns for a state.

States with fewer than five matched valid years are labeled limited coverage. Different states may still have different coverage: inspect denominators before comparing them. This report intentionally retains all 27 states, including those excluded by the main dashboard’s minimum-area filter.

Historical frequencies are descriptive, not forecast probabilities. Longer references can respond more slowly to trends and shocks. Neither reference is established as more accurate by this comparison. State aggregates cannot identify climate causes or select suppliers.
